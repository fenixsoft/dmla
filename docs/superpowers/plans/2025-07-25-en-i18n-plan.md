# DMLA 文档英文版 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 DMLA 技术文档建立英文版本，采用 VuePress 2 原生 i18n 机制，/en/ 子目录模式，AI 代理逐篇翻译+校审。

**Architecture:** 改造现有 config.js 为 locales 结构，在 docs/en/ 下建立镜像目录树，新增语言切换 Vue 组件，通过脚本驱动逐篇翻译工作流。

**Tech Stack:** VuePress 2.0.0-rc.19, Vue 3, SCSS, Node.js

## Global Constraints

- VuePress 2.0.0-rc.19，不可降级或升级
- 中文文档路径零变动
- 英文站 URL: `/en/` 子目录模式
- 图片等静态资源不复制，相对路径引用
- boards.md 中英共用，不翻译
- contents.md 由目录组件根据语言环境自动生成
- 语言切换组件位于 GitHub 图标与设置按钮之间
- 图标规格：容器 28×28px，内部 18×18px

### 原 config.js 各配置项迁移对照

将当前顶层配置迁移到 `locales` 结构，下表列出每一项的迁移目标：

| 原位置 | 配置项 | 迁移目标 |
|--------|--------|----------|
| 顶层 | `lang: 'zh-CN'` | `locales['/'].lang: 'zh-CN'` |
| 顶层 | `title: '设计机器学习应用系统'` | `locales['/'].title` |
| 顶层 | `description: ''` | `locales['/'].description` |
| `head[]` | `google: notranslate` | `locales['/'].head`（仅中文站） |
| `head[]` | `og:image` | 顶层 `head`（图片 URL 两站共用） |
| `head[]` | `og:description` | 分别移入各 locale 的 `head` |
| `head[]` | `favicon` | 顶层 `head`（共用） |
| `theme.navbar[]` | 首页、讨论区 | 分别移入各 locale 的 `theme.locales` |
| `theme.sidebar[]` | 全部侧边栏 | 分别移入各 locale 的 `theme.locales`，英文版 text 翻译 |

**保留在顶层的配置**（语言无关）：`markdown`, `head` 中的 `og:image` 和 `favicon`, `theme.logo`, `theme.colorModeSwitch`, `theme.themePlugins`, `plugins`, `bundler`, `devServer`, `base`

### Task 1: 改造 config.js — 顶层 locales 配置

**Files:**
- Modify: `docs/.vuepress/config.js`

**Interfaces:**
- Consumes: 无（第一个任务）
- Produces: 导出的 config 对象增加 `locales` 字段，`lang`/`title`/`description` 从顶层移除并移入 locales

**操作说明：** 将 `lang`, `title`, `description` 从顶层移除，head 中的 `og:description` 按语言拆分，新增 locales 顶层字段。

- [ ] **Step 1: 备份当前 config.js**

```bash
cp docs/.vuepress/config.js docs/.vuepress/config.js.bak
```

- [ ] **Step 2: 移除顶层 `lang`, `title`, `description` 字段**

在 `docs/.vuepress/config.js` 中，删除以下三行（位于 `export default {` 后的站点配置区）：
```js
lang: 'zh-CN',
title: '设计机器学习应用系统',
description: '',
```

- [ ] **Step 3: 拆分 head 数组**

从 head 数组中移除 `notranslate` meta 和 `og:description` meta，保留 `og:image` 和 `favicon` 在顶层 head：

```js
head: [
  ['meta', { name: 'og:image', content: 'https://ai.icyfenix.cn/logo_min_size.png' }],
  ['link', { rel: 'icon', href: '/favicon.ico' }],
],
```

- [ ] **Step 4: 在 head 字段之后添加 locales 顶层配置**

在 `head` 配置块之后、`theme` 配置之前插入：

```js
locales: {
  '/': {
    lang: 'zh-CN',
    title: '设计机器学习应用系统',
    description: '面向工程师从零建立机器学习的系统性理解',
    head: [
      ['meta', { name: 'google', content: 'notranslate' }],
      ['meta', { name: 'og:description', content: '面向工程师从零建立机器学习的系统性理解' }],
    ],
  },
  '/en/': {
    lang: 'en-US',
    title: 'Designing Machine Learning Applications',
    description: 'Building systematic understanding of machine learning from the ground up, for engineers',
    head: [
      ['meta', { name: 'og:description', content: 'Building systematic understanding of machine learning from the ground up, for engineers' }],
    ],
  },
},
```

- [ ] **Step 5: 语法验证**

```bash
node -e "import('./docs/.vuepress/config.js').then(m => console.log('locales keys:', Object.keys(m.default.locales)))"
```

预期输出：`locales keys: [ '/', '/en/' ]`

- [ ] **Step 6: Commit**

```bash
git add docs/.vuepress/config.js docs/.vuepress/config.js.bak
git commit -m "feat: 添加 VuePress i18n 顶层 locales 配置，拆分 lang/title/description/head 到中英双语"
```

- [ ] **Step 2: 在 `<script setup>` 中添加语言切换逻辑**

在 `import { ref } from 'vue'` 下方添加 `useRoute` 的导入，并增加语言切换相关的响应式状态和方法：

```js
import { ref } from 'vue'
import { useRoute } from '@vuepress/client'
import Settings from './Settings.vue'

const route = useRoute()

// 设置弹窗状态
const showSettings = ref(false)

// 语言切换状态
const showLocaleMenu = ref(false)
const isEnglish = ref(false)

// 根据当前路由判断语言
function updateLocaleState() {
  isEnglish.value = route.path.startsWith('/en/')
}

// 点击语言按钮时更新状态并切换下拉菜单
function toggleLocaleMenu() {
  updateLocaleState()
  showLocaleMenu.value = !showLocaleMenu.value
}

// 切换语言：根据目标语言重写当前路径
function switchLocale(target) {
  showLocaleMenu.value = false
  const currentPath = route.path

  let targetPath
  if (target === 'en') {
    // 切换到英文：在路径前加 /en/
    targetPath = '/en' + currentPath
    // 避免 /en// 的双斜线（根路径时 currentPath 以 / 结尾）
    targetPath = targetPath.replace(/\/+/g, '/')
  } else {
    // 切换到中文：去掉 /en/ 前缀
    targetPath = currentPath.replace(/^\/en/, '') || '/'
  }

  // 如果路径没变，不跳转
  if (targetPath !== currentPath) {
    window.location.href = targetPath
  }
}

// 点击外部关闭下拉菜单
if (typeof document !== 'undefined') {
  document.addEventListener('click', (e) => {
    // 如果点击的不是语言切换区域内的元素，关闭菜单
    const target = e.target
    if (!target.closest('.locale-switcher')) {
      showLocaleMenu.value = false
    }
  })
}
```
