# DMLA 文档英文版设计

## 概述

为 DMLA 技术文档建立英文版本，采用 VuePress 2 原生 i18n 机制，通过 `/en/` 子目录模式提供服务。翻译工作由 AI 代理逐篇完成，每篇文章经翻译和校审两个阶段后进入下一篇。

## 目标

- 在 `docs/en/` 下建立与中文文档完整镜像的英文目录树
- 英文站点通过 `ai.icyfenix.cn/en/` 访问，中文站路径保持不变
- 每篇文章经过 AI 翻译代理和校审代理双重把关，保证技术准确性和术语一致性

## 技术方案：VuePress 原生 i18n + 文档镜像目录

### 站点配置（docs/.vuepress/config.js）

将当前单语言配置改造为 `locales` 结构。站点级通用配置（markdown、bundler、plugins 等）保留在外层，语言相关配置移入 `locales`：

```js
export default {
  // 站点级通用配置保留
  markdown: { breaks: true },
  bundler: viteBundler({ ... }),
  plugins: [ ... ],

  locales: {
    '/': {
      lang: 'zh-CN',
      title: '设计机器学习应用系统',
      description: '面向工程师从零建立机器学习的系统性理解',
      head: [
        ['meta', { name: 'google', content: 'notranslate' }],
        ['meta', { name: 'og:description', content: '面向工程师从零建立机器学习的系统性理解' }],
      ],
    },
    '/en/': {
      lang: 'en-US',
      title: 'Designing Machine Learning Applications',
      description: 'Building systematic understanding of machine learning from the ground up, for engineers',
      head: [
        ['meta', { name: 'og:description', content: 'Building systematic understanding of machine learning from the ground up, for engineers' }],
      ],
    },
  },

  theme: dmlaTheme({
    logo: '/logo_min_size.png',
    colorModeSwitch: false,
    themePlugins: { ... },

    locales: {
      '/': {
        navbar: [
          { text: '首页', link: '/' },
          { text: '讨论区', link: '/boards' },
        ],
        sidebar: [ /* 现有中文侧边栏，不变 */ ],
      },
      '/en/': {
        navbar: [
          { text: 'Home', link: '/en/' },
          { text: 'Discussion', link: '/boards' },
        ],
        sidebar: [ /* 英文侧边栏，text 字段翻译，link 加 /en/ 前缀 */ ],
      },
    },
  }),
}
```

关键点：
- 中文站的 `notranslate` meta 仅保留在 `/` locale 的 `head` 中，英文站不设此限制
- `og:description` 按语言分别设置
- 搜索插件 `searchProPlugin` 自动为每个 locale 建立独立索引，无需额外配置
- 侧边栏仅翻译 `text` 字段（导航标签），`link` 路径加 `/en/` 前缀

### 目录结构

```
docs/
  ├── README.md                    # 中文首页
  ├── boards.md                    # 留言板（中英共用）
  ├── contents.md                  # 目录文件（中英共用）
  ├── introduction/                # 现有中文文档，全部不变
  ├── maths/
  ├── statistical-learning/
  ├── deep-learning/
  ├── language-models/
  ├── ai-infra-engineering/
  ├── agent-applications/
  ├── appendixes/
  └── en/                          # 英文镜像目录
      ├── README.md
      ├── contents.md               # 目录组件，根据语言环境自动生成
      ├── introduction/
      ├── maths/
      ├── statistical-learning/
      ├── deep-learning/
      ├── language-models/
      ├── ai-infra-engineering/
      ├── agent-applications/
      ├── appendixes/
      └── _translation-progress.md # 翻译进度追踪文件
```

规则：
- `boards.md` 不翻译，不在 `docs/en/` 下创建。中英文用户共用一个留言板页面，评论在同一个页面中直接混合显示。英文导航栏中 link 直接指向 `/boards`
- `contents.md` 不翻译（目录由组件自动生成），但需在 `docs/en/` 下创建，目录组件根据当前语言环境（URL 中的 `/en/` 前缀）自动生成对应语言的目录内容。英文侧边栏中 link 指向 `/en/contents`
- 所有章节包括 `appendixes/` 均纳入翻译范围
- 静态资源（图片、Logo 等）不复制，英文文档通过相对路径 `../introduction/assets/...` 引用
- 英文文档间交叉引用链接统一加 `/en/` 前缀

### 语言切换组件

在 `docs/.vuepress/theme/components/NavbarSettings.vue` 中新增语言切换按钮，放置于 GitHub 图标和设置按钮之间。

**图标设计**：SVG 图标，左侧 "EN"、右侧 "中"，中间以 45 度斜线分隔。容器 28×28px，内部图标区域 18×18px，与 GitHub 和设置图标规格一致。

**交互行为**：点击图标弹出下拉菜单，列出两个选项：
- "中文"（路由 `/`）
- "English"（路由 `/en/`）

当前语言对应选项高亮。点击非当前语言时，自动切换到目标语言下对应的页面路径（例如在 `/deep-learning/cnn-basics.html` 点击 "English" 后跳转到 `/en/deep-learning/cnn-basics.html`）。

**样式**：按钮样式（尺寸、边框圆角、hover 效果、颜色变量）与现有 `github-link` / `settings-btn` 一致，确保视觉统一。

## 翻译工作流

### 总体流程

逐篇文章串行处理，每篇文章内翻译和校审两个子代理并行工作，两者完成后进入下一篇文章。翻译顺序按侧边栏章节递进：前言 → 数学基础 → 统计学习 → 深度学习 → 语言模型 → AI 基础设施 → Agent 应用 → 附录。

### 翻译代理

输入：
- 中文 Markdown 原文
- 该章节领域的术语表（按领域维护，如线性代数术语表、Transformer 术语表等，保证全书译名一致）
- 翻译约束指令

翻译约束：
- Markdown 结构标记、HTML 标签、自定义 Vue 组件（如 `<Demo>`、`<Runnable>`）原样保留
- LaTeX 数学公式原样保留
- 代码块原样保留，但其中的中文注释、print 输出内容、图表图例等文字需要翻译
- 内部链接路径加 `/en/` 前缀
- 中文人名格式 "中文译名（英文名）" 反转英文文档中为 "英文名"

输出：完整的英文 Markdown 文件，写入 `docs/en/` 对应路径。

### 校审代理

校审从更高层面做质量把关，不作为逐句对照：

- 术语一致性检查：同一术语在本文内及跨文档是否译名统一
- 技术准确性：专业概念的英文表述是否有事实性错误
- 可读性：英文是否自然通顺，非母语读者是否能流畅理解
- 遗漏检查：是否有整段内容、公式、代码块被意外丢弃

输出：通过/需修改的判断，如需修改附具体修改建议。

### 术语表维护

术语表按章节领域分别维护在 `docs/en/_glossary/` 下，如：
- `linear-algebra.md` — 向量、矩阵、特征值等
- `calculus.md` — 导数、梯度、链式法则等
- `transformer.md` — 注意力、多头、位置编码等

翻译代理以对应章节的术语表作为输入参考，校审代理在检查后如果发现术语表中未涵盖的新术语或译文有误，在进度追踪文件中记录建议，由人工统一确认后更新术语表。

### 进度追踪

`docs/en/_translation-progress.md` 维护每篇文章的状态：

```markdown
| 文件路径 | 状态 | 翻译代理 | 校审代理 | 备注 |
|---------|------|---------|---------|------|
| introduction/about-dmla.md | 校审完成 | ✓ | ✓ | |
| introduction/about-me.md | 翻译完成 | ✓ | 待校审 | |
| maths/linear/vectors.md | 待翻译 | - | - | |
```

状态流转：待翻译 → 翻译完成 → 校审完成（可上线）。

## 构建与部署

### 构建

`vuepress build docs` 自动处理 i18n 构建，英文文档输出到 `dist/en/`。构建命令和流程无需变化。

### 部署

站点部署在域名根路径（`base` 配置为 `/`），GitHub Pages 托管。子目录模式 `docs/en/` 构建后 URL 天然为 `ai.icyfenix.cn/en/...`，部署流程不变。

### 搜索

`searchProPlugin` 自动按 locale 隔离搜索索引，中文用户搜索中文内容，英文用户搜索英文内容，互不干扰。

## 需修改的文件清单

| 文件 | 修改内容 |
|------|---------|
| `docs/.vuepress/config.js` | 添加 `locales` 配置，拆分语言相关的 title/description/head/navbar/sidebar |
| `docs/.vuepress/theme/components/NavbarSettings.vue` | 新增语言切换按钮和下拉菜单 |
| `docs/.vuepress/theme/layouts/Layout.vue` | 无需修改（已引用 NavbarSettings） |
| `docs/en/` | 新建目录，逐篇写入翻译文档 |
